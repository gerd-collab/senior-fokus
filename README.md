# Fokuspunkt

Launcher für Senioren-Apps (Vite + Vanilla TS). Übersichtsseite mit 37 Apps;

- Dev: `npm run dev`
- Build: `npm run build`
- Deep-Link: `/?app=<id>` direkt in eine App
- App-Liste und Details in `src/apps.ts` (id, Titel, Beschreibung, URL, Screenshot).
  Screenshots liegen in `public/app-screenshots/`.

Deploy: Vercel, Framework-Preset "Vite" funktioniert direkt.
